# Landing page for BuildTogether

`landing-page.html` is the landing page design. Download it and double-click it to view it in a browser.

It follows our `DESIGN.md` (Nordic Oat: oat background, fjord blue, ochre accent, Inter).

## Add it to the Lovable project

Paste this prompt into Lovable and attach `landing-page.html` (or paste its code below the prompt):

```
Add a public landing page at "/" for logged-out visitors, matching the attached HTML exactly: same text, sections, order, colours, spacing and fonts. Follow DESIGN.md. Rebuild it with our existing components, do not embed the HTML file.

- "Create your profile" buttons go to our registration page.
- "Log in" goes to our login page.
- Logged-in users skip this page and land in the app as before.
- Keep the page responsive: on a phone, all columns stack.
- Do not change any other page, the login flow or the security rules.
```

## Check before it goes live

- The Trust section says accounts are confirmed by email, there are no social logins, and the AI is from Mistral. Change the text if the app works differently.
- Mette and Sofie in the example card are fictional personas (see `personas.md`).
